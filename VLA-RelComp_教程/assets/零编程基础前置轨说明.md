# 真正零编程基础者的前置轨说明

Day 0—14 不是编程入门课。它默认学习者有 408/C 基础，并接触过少量 Python、Linux 和 Git。若你真正从未写过程序，先在仓库外补齐以下就绪条件，不把它们塞进 14 天必修：

- 能在终端中用 `pwd`/`ls`/`cd` 定位文件，并知道命令可能修改文件；
- 能用任一文本编辑器复制文件、改一个 Python 数值并保存；
- 能读懂 Python 的变量、list/dict、`for`、函数、`import` 和 traceback 首个有效错误；
- 能运行 `python3 script.py`，并分清标准输出、标准错误和退出码；
- 知道 CSV/JSON 是结构化文本，能按列名查一行；
- 能使用 `git clone/status/diff`，不会把 token、密码或私钥写进仓库。

就绪标准是：在一个与本项目无关的临时文件中，独立写并运行 15—30 行 Python，读入两行 CSV、改一个字段、输出 JSON，遇到一次语法错误能根据 traceback 修正。达到后再从 Day 0 开始。

本文不指定新的 Python/conda/CUDA 环境，不引入第二套 VLA 课程，也不代替正式参考运行。
