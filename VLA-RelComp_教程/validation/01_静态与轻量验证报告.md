## 发现并消解的版本风险

1. README 用展示短名 `preposition_combinations`，代码使用 `extrapolation_preposition_combinations`；教程执行配置统一使用后者。
2. README 允许 macOS 12+ 安装且 GPU 路径需 CUDA 11.8+。教程只在 Mac 做纯脚本/静态核验，正式 Gate 明确使用 Linux/NVIDIA。
3. 上游默认 YAML 指向其他 suite；教程复制成项目自有 smoke 配置，不修改 upstream，并关闭 language replacements。
4. PyTorch 原稳定别名页面抓取不稳定；资料索引改为可访问的官方 docs 域名/version-specific inference-mode 页面并重新检查 200。
5. 当前 Python 没有 PyYAML；未安装新依赖，沿用 Ruby 标准 YAML 解析器复核三份配置均为 `Hash`。
