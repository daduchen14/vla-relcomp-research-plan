> 日期：2026-08-26；分支：`h2-linux-nvidia-preflight`；起点：`fba7a7fc17c240f2f1d2ce5c245bc00704e6efa9`。本报告仅覆盖免费、静态、dry-run 和 synthetic fixture 验证。

## 结论

Fresh clone 路径、教程根/上游显式定位、关键 CLI 参数回归、只读统一入口和 C7 配对统计已补齐。没有运行 VLA-Arena episode、MuJoCo、checkpoint、CUDA kernel、模型/数据下载、训练或 Gate 1–3 判定。

H2.5.1 将私库入口改为 HTTPS tag 克隆并将 VLA-Arena 放到 repo 外 sibling，但正式 tag-only clone 复核发现 isolated validator 内部仍硬编码克隆 `h2-linux-nvidia-preflight` 开发分支。tag-only source 没有该本地 branch ref，因此 H2.5.1 的 isolated fresh 验收为 **FAIL**。已有 `vla-relcomp-h2.5.1` 保留不变，不再作为当前入口。

H2.5.2 将全部 release fixture 和 `validate_external_default` 改为从 `RELEASE_TAG` 克隆，并在临时 Git 中显式构造“有 release tag、无本地开发分支”的 source，再从该 source 运行完整 H2/isolated 回归。当前唯一受审入口为 lightweight tag `vla-relcomp-h2.5.2`。

## 修复内容

- `fresh_clone_quickstart.md` 锁定不可覆盖的 lightweight tag `vla-relcomp-h2.5.2`；`setup/doctor` 必须验证 HEAD 与 tag commit 严格相等，tag 之后的开发分支提交会被拒绝。教程根从 Git 自动定位。
- 默认私库命令是 HTTPS `--branch vla-relcomp-h2.5.2 --single-branch`；凭据交给 Git Credential Manager/已登录 GitHub 凭据链，SSH 仅作已验证公钥的可选替代，禁止将 PAT 嵌入 URL。
- `setup --dry-run` 默认把上游解析为项目仓库外的 sibling `VLA-Arena-upstream`；本地 Git 端到端 fixture 验证创建该 sibling 后项目仍是 clean，`doctor` 为 `ready`。
- Day 0/1/2/5/10 的作者绝对路径、Day 3/5 的隐式旧 upstream 路径均替换为可移植变量；`validate_upstream.py` 文档调用恢复为唯一位置参数。
- `vla_relcomp.py` 提供 `doctor`、`setup --dry-run`、`status`、`resume`和 `smoke`。它只读或打印 argv，不跳过检查点状态机、不执行 episode、不自动作研究 Gate 判断。
- `analyze_c7.py` 以 manifest-bound 审计为前置，输出四格、recovery/damage、Wilson 95% CI、精确 McNemar 和 task/seed/init 分层；异常、缺行失败，零分母输出 `null`。
- Day 12 的 language oracle 统一为 `target/action=place/relation/reference` 四字段。Visual oracle 在 Day 12、H2、Gate 3 和 sample fixture 统一标为“规范已有、执行未实现、不可运行”。
- 主课受众明确为冻结画像；真正零编程基础者只获得独立就绪门槛说明，未增加第二套 14 天课程。
