- `fresh_clone_quickstart.md` 锁定私有分支，用 `merge-base --is-ancestor` 验证 H2.4 基线并允许后续修复提交；教程根从 Git 自动定位。

- `vla_relcomp.py` 提供 `doctor`、`setup --dry-run`、`status`、`resume`和 `smoke`。它只读或打印 argv，不跳过检查点状态机、不执行 episode、不自动作研究 Gate 判断。

- Day 12 的 language oracle 统一为 `target/action=place/relation/reference` 四字段。Visual oracle 在 Day 12、H2、Gate 3 和 sample fixture 统一标为“规范已有、执行未实现、不可运行”。
- 主课受众明确为冻结画像；真正零编程基础者只获得独立就绪门槛说明，未增加第二套 14 天课程。
