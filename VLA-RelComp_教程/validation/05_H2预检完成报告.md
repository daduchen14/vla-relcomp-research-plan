## 静态核验与已消解差异

1. 官方 evaluator 的 `num_trials_per_task: 1` 是 5 tasks×1，不是单 episode；`h2_one_episode.py` 固定 task/init 并只调用锁定初始化/环境/episode 函数。
2. 锁定提交的 `envs/base` 只有 `uv.lock`而没有 `pyproject.toml`；random 沿用 Smol 隔离 venv 中的 base 依赖，不加载 checkpoint。
3. SmolVLA Hub 的可加载文件在 `pretrained_model/`；渲染配置使用已校验的本地子目录。
4. 官方 pilot 只输出汇总 JSON；`h2_pilot.py` 仅外层包装锁定 `run_task/run_episode`，一次加载模型并记录每个 episode。
5. 多 trial 使用 `first` 会重复初态；H2 t5 渲染固定为 `episode_idx`，使用 init 0–4 且逐行记录。
6. L0 task 0 的 BDDL `obj_of_interest=tomato_2`，但 goal 是 `On(tomato_3, porcelain_bowl_3)`；C6 以 goal 实例为诊断目标，不误用 `obj_of_interest`。

这些是可回滚的 wrapper/配置处理，没有修改 upstream tracked file。锁定上游工作树仍干净。
